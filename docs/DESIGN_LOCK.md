# Roaring Fork Local — Approved Homepage Design Lock

The current homepage design is APPROVED and should be treated as the visual baseline.

## Approved homepage

The homepage must preserve:

- Cream / off-white header
- Roaring Fork Local mountain logo at upper left
- Navigation:
  - Home
  - Eat
  - Marketplace
  - Events
  - Jobs
  - Housing
  - Vote
- "Post a listing" link
- Account icon on the far right

## Hero

The approved hero uses:

- Full-width Roaring Fork Valley autumn mountain / river image
- Left-aligned headline:
  "The valley, all in one place."
- Supporting text:
  "Food, work, housing & community from Aspen to Rifle"
- Large white search field
- Town selectors:
  All · Aspen · Basalt · Carbondale · Glenwood · Rifle

## Category strip

Directly below the hero:

- Eat
- Shop
- Live
- Work
- Gather
- Voice

## Design rule

Do NOT redesign, replace, re-center, simplify, modernize, or substantially alter:

- header layout
- logo placement
- primary navigation
- hero composition
- hero image
- headline placement
- search field
- town selector layout
- category strip
- overall cream / green / ochre visual language

unless the owner explicitly approves a new design.

Feature work should preserve this visual system.

## Approved reference

The approved homepage is the autumn mountain / river design with the headline:

"The valley, all in one place."

If later code conflicts with this design, this approved design takes priority.
